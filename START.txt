ПРОСТОЙ ПРОЕКТ: GO + MYSQL + ANGULAR

СТРАНИЦЫ
/register — регистрация.
/login — вход.
/requests — свои заявки и отзыв о завершённой заявке.
/requests/new — создание заявки: помещение, дата, оплата.
/requests/ID/edit — изменение заявки.
/admin — все заявки, фильтр и смена статуса (только администратор).

1. СОЗДАНИЕ БАЗЫ В MYSQL WORKBENCH
Запусти сервер MySQL и открой Workbench.
Нажми + возле MySQL Connections.
Connection Name: Практика. Hostname: 127.0.0.1. Port: 3306.
Username: твой пользователь MySQL, например root.
Test Connection: введи пароль. Нажми OK и открой подключение.
File > Open SQL Script: выбери backend/schema.sql.
Нажми молнию для выполнения ВСЕГО файла без выделения отдельных строк.
Создадутся база demo_exam и таблицы users, sessions, requests.
Обнови SCHEMAS слева.
База demo_simple и её bookings не используются в этой версии.

2. НАСТРОЙКИ
В начале backend/main.go замени YOUR_MYSQL_USER и YOUR_MYSQL_PASSWORD.
Там же находятся адрес MySQL, имя базы и данные администратора.
Администратор автоматически создаётся при первом запуске Go:
логин Conf2027, пароль Demo77.
Существующий администратор при повторном запуске не изменяется.
Если меняешь пароль администратора в коде после первого запуска,
пароль уже созданного пользователя в базе останется прежним.

3. ЗАПУСК
Нужны Go 1.22+ и Node.js ветки 22 версии 22.12 или новее.
Первый терминал, папка backend:
go mod download
go run .

Второй терминал, папка frontend:
npm ci
npm start

Открой http://127.0.0.1:4200
После изменения Go перезапусти его: Ctrl+C, затем go run .
Angular подхватывает изменения автоматически.

4. ЧТО ПРОВЕРИТЬ ВРУЧНУЮ
Зарегистрируйся: логин от 6 латинских букв/цифр, пароль от 8 символов,
ФИО кириллицей, телефон 8(999)123-45-67, email.
Создай заявку. Обнови страницу: заявка осталась.
Измени заявку. Выйди и войди администратором.
На странице /admin измени статус заявки на Завершено.
Выйди, войди обычным пользователем и оставь отзыв.
Удаление и изменение доступны владельцу заявки.

5. ГДЕ КОД
backend/main.go — настройки, запуск, маршруты и создание администратора.
backend/auth.go — регистрация, вход и cookie-сессия.
backend/requests.go — заявки, отзывы и админка.
backend/validation.go — проверка полей.
backend/web.go — чтение JSON, ответы и проверка источника запросов.
backend/schema.sql — создание БД в Workbench.
frontend/src/app/pages — страницы, у каждой TS и HTML.
frontend/src/app/app.routes.ts — адреса страниц.
frontend/src/app/api.service.ts — запросы по заявкам.
frontend/src/app/auth.service.ts — вход и текущий пользователь.
frontend/src/app/models.ts — интерфейсы.
frontend/src/styles.scss — минимальное оформление.

Git, Docker, .env, тесты и служебные скрипты для запуска не нужны.
Скачать: GitHub > Code > Download ZIP.
Зависимости установи заранее с интернетом на целевой ОС.
Для офлайн-запуска сохрани node_modules и кэш Go-модулей.
Это основа приложения по модулям 1–3: отдельный GET /orders,
дизайн-макеты и экзаменационные материалы здесь не реализованы.

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
Angular: скачай всю папку frontend, включая package-lock.json и tsconfig-файлы.
Открой терминал именно в frontend, выполни npm ci, затем npm start.
node_modules создаётся командой npm ci и не хранится на GitHub.
Не переноси node_modules с Windows на Linux: установи зависимости на Linux.
Папка .angular — автоматически создаваемый кэш, вручную восстанавливать её не нужно.
public — картинки и favicon; app.scss — стили оболочки; styles.scss — общие стили.

Linux, ошибка компилятора про stdint.h: попробуй из backend:
CGO_ENABLED=0 go run .
Если ошибка остаётся, нужен полный текст ошибки и вывод go version.
