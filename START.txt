БАЗОВЫЙ ПРОЕКТ: GO + MYSQL + ANGULAR

Одна таблица и одна страница: создание, список, изменение, удаление заявок.
Авторизации, ролей, оплаты, статусов и отзывов в этой версии нет.

1. БАЗА ЧЕРЕЗ MYSQL WORKBENCH
Запусти установленный сервер MySQL и открой Workbench.
Нажми + возле MySQL Connections.
Connection Name: Практика. Hostname: 127.0.0.1. Port: 3306.
Username: твой пользователь MySQL, например root.
Нажми Test Connection, введи пароль, затем OK.
Открой подключение двойным щелчком.
File > Open SQL Script: выбери backend/schema.sql.
Нажми молнию для выполнения всего файла, без выделения отдельных строк.
Создадутся база demo_simple и таблица bookings.
Обнови список SCHEMAS слева.
Для просмотра данных выполни: SELECT * FROM demo_simple.bookings;

2. НАСТРОЙКИ
В backend/main.go замени YOUR_MYSQL_USER и YOUR_MYSQL_PASSWORD.
config.Addr — адрес MySQL и порт. config.DBName — имя базы.
При смене имени базы поменяй его также в schema.sql.

3. ЗАПУСК
Нужны Go 1.22+ и Node.js ветки 22 версии 22.12 или новее.
Терминал в папке backend:
go mod download
go run .

Второй терминал в папке frontend:
npm ci
npm start

Открой http://127.0.0.1:4200
Оба терминала должны работать одновременно.
После изменений Go: Ctrl+C и снова go run .
Angular подхватывает изменения автоматически.

4. ПРОВЕРКА ВРУЧНУЮ
Создай заявку и обнови страницу: заявка осталась.
Измени помещение, сохрани и обнови страницу: изменение осталось.
Удали заявку и обнови страницу: она не вернулась.
404/405 после правок Go: перезапусти Go.
Ошибка БД: проверь запуск MySQL, имя базы, пользователя, пароль, порт.

5. ФАЙЛЫ
backend/main.go — настройки БД и HTTP-обработчики.
backend/schema.sql — создание БД через Workbench.
frontend/src/app/app.ts — форма и запросы.
frontend/src/app/app.html — разметка.
frontend/src/styles.scss — оформление.
frontend/proxy.conf.json — пересылка /api на Go.

Git, Docker, .env и служебные скрипты для запуска не нужны.
На GitHub выбери Code > Download ZIP и распакуй проект.
Зависимости установи заранее с интернетом на целевой ОС.
Для офлайн-запуска сохрани node_modules и кэш Go-модулей.
